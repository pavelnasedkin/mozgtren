# МозгТрен

Мини-игры для тренировки мозга: чистые **HTML + CSS + JavaScript**, без сборки. Работает в браузере на телефоне через интернет.

## Игры

- **Память** — найти пары карточек
- **Струп** — выбрать цвет надписи, не читая слово
- **Счёт** — примеры на скорость (экранная клавиатура)
- **Саймон** — повторить последовательность цветов
- **Ежедневная тренировка** — 3 случайные игры подряд

Прогресс (серия дней, рекорды) хранится в `localStorage` на устройстве.
